# Product scope — XIS Unified MVP

## Product goal
Help South African businesses discover relevant tender opportunities and help issuing organisations publish notices and review submissions in one workspace.

## Primary roles
- **Bidder / tenderpreneur:** searches tenders, maintains a business capability profile, prepares and submits a proposal.
- **Issuing agency:** publishes tender information and reviews received submissions.
- **Platform administrator (future):** verifies organisations, manages access, moderates data and audits activity.

## MVP acceptance checklist
- [x] Browse seeded tenders.
- [x] Search tender titles, descriptions, categories and agencies.
- [x] Create a business profile and persist it locally.
- [x] Publish a tender notice in the local demo.
- [x] Submit a demo bid against an open tender.
- [x] View received submissions in agency review.
- [x] Show simple explainable keyword matches between profile capabilities and tender text.
- [ ] Authentication and role-based permissions.
- [ ] Live official tender feeds and source citations.
- [ ] Secure attachment handling and tender-document versioning.
- [ ] Automated tests and production deployment.

## Non-goals in this build
No automatic award decisions, no guarantee of tender eligibility, no scraping of restricted sources, no live government integrations, and no claim of procurement compliance.
